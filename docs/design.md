# life 设计说明

## 方向

像一本持续更新的个人生活杂志。让照片和每一次记录成为主角，使用清楚的主题入口，不加入多余的仪表盘、登录、评分或社交功能。

## 视觉

| 元素 | 设计 |
| --- | --- |
| 背景 | 纯白 `#ffffff` |
| 主文字 | 近黑 `#202124` |
| 次要文字 | 中性灰 `#737478` |
| 强调色 | 赛车红 `#d63b24`，用于标点、当前导航和 F1 标签 |
| 中文 | Noto Sans SC / 系统无衬线字体 |
| 英文品牌 | Georgia 斜体，形成 `life.` 的大字标识 |
| 分隔 | 细线，少用背景色和卡片边框 |
| 图片 | 方正裁切，不加大圆角和阴影 |
| 动效 | 图片轻微缩放，尊重减少动态效果的系统偏好 |

## 页面

- **首页 `/life/`**：最近的一篇记录采用大图，其余记录使用较小卡片；下方提供三个栏目索引。顶部简短介绍，不设置多余的订阅或宣传区。
- **分类 `/life/f1/`、`/life/food/`、`/life/photography/`**：使用同一套结构，保留每个主题自己的简介与图像气质。
- **文章 `/life/posts/slug/`**：标题、日期、主题、位置和封面在前；正文宽度限制在 700 像素，适合长时间阅读。文章可以以图片为主，不强制小标题数量。
- **关于 `/life/about/`**：简短介绍，以及学术主页和 GitHub 入口。

## 内容建议

F1 可记录比赛名称、观赛方式、看台位置和印象深刻的瞬间；探店可记录店名、点单、环境与是否想再次到访；摄影可记录地点、天气、拍摄动机和图集。器材、价格和比赛结果按需要加入，不强制每篇都填满。

## 手机

导航保持在同一屏内可见。首页和分类切换为单列，图片比例更适合窄屏，标题与正文保留足够行距。所有主要阅读内容都有系统字体回退；图片预留尺寸，减轻加载时的跳动。

## 后续扩展

先保持三个栏目和 Markdown 更新流程。记录明显增多时再考虑分页；确实需要查找历史内容时再加入搜索。摄影文章可直接插入多张照片，无需先做复杂图库系统。
